|ЗАПУСТИТЬ ПРИЛОЖЕНИЕ И СЕРВЕР|
|_____________________________|

1. Добавить репозиторий Microsoft
wget https://packages.microsoft.com/config/ubuntu/24.04/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
rm packages-microsoft-prod.deb

2. Установить SDK и Runtime
sudo apt update
sudo apt install -y dotnet-sdk-10.0

3. Создать папку app в домашнем каталоге
mkdir app

4. Клонировать репозиторий
cd app
git clone https://github.com/temameta/SimpleApiApp.git .

5. Перейти в папку с проектом
cd app

6. Собрать и опубликовать в /var/www/app
dotnet publish -c Release -o /var/www/app

7. Выставить права 755
sudo chmod -R 755 /var/www/app
sudo chown -R $USER:$USER /var/www/app

8. Создать systemd сервис
sudo nano /etc/systemd/system/simpleapiapp.service

	Вставить следующее:

[Unit]
Description=SimpleApiApp .NET Web API
After=network.target

[Service]
WorkingDirectory=/var/www/app
ExecStart=/usr/bin/dotnet /var/www/app/SimpleApiApp.dll
Restart=always
RestartSec=10
KillSignal=SIGINT
SyslogIdentifier=simpleapiapp
User=www-data
Environment=ASPNETCORE_ENVIRONMENT=Development
Environment=DOTNET_PRINT_TELEMETRY_MESSAGE=false

[Install]
WantedBy=multi-user.target


9. Перезагрузить демоны и запустить сервис
sudo systemctl daemon-reload
sudo systemctl enable simpleapiapp
sudo systemctl start simpleapiapp

10. Проверить статус
sudo systemctl status simpleapiapp

11. Проверить что API отвечает на порту 5000
curl http://localhost:5000/api/health

12. Установить Nginx
sudo apt install -y nginx

13. Создать конфиг для сайта
sudo nano /etc/nginx/sites-available/simpleapiapp.conf

	Вставить следующее:

server {
    listen 80;
    server_name simpleapiapp.com;

    location / {
        proxy_pass         http://localhost:5000;
        proxy_http_version 1.1;
        proxy_set_header   Upgrade $http_upgrade;
        proxy_set_header   Connection keep-alive;
        proxy_set_header   Host $host;
        proxy_set_header   X-Real-IP $remote_addr;
        proxy_set_header   X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header   X-Forwarded-Proto $scheme;
        proxy_cache_bypass $http_upgrade;
    }
}

14. Активировать конфиг
sudo ln -s /etc/nginx/sites-available/simpleapiapp /etc/nginx/sites-enabled/

15. Переместить дефолтный конфиг чтобы не конфликтовал
cd ..
sudo mv /etc/nginx/sites-enabled/default .

16. Проверить конфиг на ошибки
sudo nginx -t

17. Перезапустить Nginx
sudo systemctl restart nginx
sudo systemctl enable nginx

18. Проверить статус
sudo systemctl status nginx

19. Разрешить подключение к портам
sudo ufw allow 80/tcp
sudo ufw allow 5000/tcp
sudo ufw status

 _____________
|             |
|НАСТРОИТЬ SSH|
|_____________|

1. Проверить установлен ли SSH
ssh -V

	Покажет версию, например OpenSSH_9.6p1

2. Проверить статус службы SSH
sudo systemctl status ssh

3. Если SSH не установлен — установить
sudo apt update
sudo apt install -y openssh-server

4. Запустить и добавить в автозапуск
sudo systemctl start ssh
sudo systemctl enable ssh

 ___________________
|                   |
|МОНТИРОВАНИЕ ФЛЕШКИ|
|___________________|

1. Установить поддержку NTFS
sudo apt install -y ntfs-3g

2. Создать точку монтирования
sudo mkdir -p /mnt/usb

3. Посмотреть как система определила флешку
sudo fdisk -l /dev/sdb

4. Смонтировать флешку
sudo mount -t ntfs-3g /dev/sdb4 /mnt/usb

5. Просмотр файлов флешки
ls /mnt/usb

РАЗМОНТИРОВАТЬ ФЛЕШКУ

1. Выйти из папки с флешкой
cd ~

2. Сбросить буферы записи на диск
sync

3. Размонтировать флешку
sudo umount /mnt/usb

4. Проверить что флешка размонтирована
lsblk

	Рядом с /dev/sdb4 НЕ должно быть точки монтирования

5. Отключить флешку от VM в VirtualBox
Меню VirtualBox → Устройства → USB → сними галочку ✔️ с флешки
